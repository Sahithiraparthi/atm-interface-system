# atm-interface-system
Java-based ATM Interface System implementing banking operations such as withdrawal, deposit, balance inquiry, and user authentication using Object-Oriented Programming concepts.
## Features
- User Login Authentication
- Deposit Money
- Withdraw Money
- Balance Inquiry
- Console-based Menu System
- OOP-based Java Design

## Technologies Used
- Core Java
- OOP Concepts
- Scanner Class

## Concepts Implemented
- Classes and Objects
- Methods
- Loops
- Conditional Statements
- User Input Handling
